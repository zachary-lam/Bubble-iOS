## About The Project
This starter project is for my personal practice with the Swift programming language and the UIKit framework using Xcode Storyboards. Through this project, I practice applying the Model-View-Controller (MVC) design pattern and managing dependencies with a combination of CocoaPods and Swift Package Manager (SPM).

Additional skills demonstrated in this project include integrating backend APIs, navigating between view controllers using navigation controllers and segues, and updating UI state with table views.

### Features
- [x] Native application
- [x] Support for iOS 13.0+
